# 1. VISÃO DO PRODUTO

O produto se chama:

# NURA

A NURA será uma plataforma digital premium de:

- avaliações;
- testes interativos;
- autoconhecimento;
- cognição;
- personalidade;
- comportamento;
- carreira;
- atenção;
- neurodiversidade.

A NURA NÃO deve ser percebida simplesmente como:

> "um site de testes online".

Queremos construir um ecossistema no qual o usuário começa realizando uma avaliação específica e, progressivamente, descobre diferentes dimensões sobre si mesmo.

A proposta conceitual é:

# Descubra mais sobre você.

Em inglês:

# Discover what makes you, you.

---

# 2. POSICIONAMENTO

A percepção desejada da NURA é a combinação de:

**Tecnologia**

+

**Ciência**

+

**Descoberta pessoal**

+

**Curiosidade**

+

**Confiança**

+

**Experiência premium**

A experiência precisa ser moderna e sofisticada sem parecer clínica demais.

Também não deve parecer:

- cassino;

- Web3;

# 3. PRINCÍPIO CENTRAL DO PRODUTO

A lógica de negócio da NURA será:

> O teste gera aquisição.
>
> O resultado gera curiosidade.
>
> O relatório aprofundado gera monetização.
>
> O NURA Perfil gera retenção.
>
> Novas avaliações aumentam recorrência.

Portanto:

```text
DESCOBERTA
      ↓
AVALIAÇÃO
      ↓
RESULTADO
      ↓
APROFUNDAMENTO
      ↓
NURA PERFIL
      ↓
NOVA DESCOBERTA
```

A NURA não deve depender exclusivamente de assinatura mensal.

Inicialmente, a monetização principal será transacional.

# 7. O QUE O USUÁRIO RECEBE GRATUITAMENTE

O resultado gratuito precisa entregar valor real.

Não criar um paywall onde absolutamente tudo fica escondido.

O usuário poderá receber, dependendo da avaliação:

- classificação inicial;
- perfil predominante;
- score ou faixa quando metodologicamente aplicável;
- resumo;
- principal característica encontrada;
- pequena interpretação.

Exemplo conceitual:

```text
SEU RESULTADO

Perfil predominante

ANALÍTICO

Principal destaque

RECONHECIMENTO DE PADRÕES

87/100

[ Ver análise completa ]
```

O resultado real dependerá da metodologia de cada avaliação.

# 9. NURA PERFIL

Um dos principais diferenciais da plataforma será:

# NURA Perfil

O NURA Perfil é o perfil evolutivo do usuário dentro do ecossistema NURA.

Cada avaliação realizada revela uma nova dimensão.

Exemplo:

```text
NURA PERFIL

42% explorado

Cognição          ●
Atenção           ●
Personalidade     ●
Comportamento     ●
Carreira          ○
```

O percentual representa:

# quanto do ecossistema NURA foi explorado.

NÃO representa:

- inteligência geral;
- saúde mental;
- qualidade da pessoa;
- diagnóstico;
- performance universal;
- "quanto a pessoa se conhece".

---

# 10. NURA PERFIL NÃO É UMA NOTA

Não combinar artificialmente:

- QI;
- TDAH;
- autismo;
- personalidade;
- inteligência emocional;

em uma única pontuação.

São construtos diferentes.

Cada avaliação mantém:

- metodologia própria;
- dimensões próprias;
- interpretação própria.

O NURA Perfil funciona como:

# mapa de descobertas.

Não como score universal.

# 16. METODOLOGIA DOS TESTES

Não inventar instrumentos científicos.

Antes de implementar qualquer avaliação real:

1. identificar metodologia;
2. verificar licenciamento;
3. verificar direitos autorais;
4. verificar validade;
5. verificar população-alvo;
6. verificar scoring;
7. verificar limitações;
8. verificar linguagem permitida.

Não copiar perguntas de plataformas concorrentes.

Instrumentos proprietários ou protegidos devem ser utilizados somente quando houver autorização/licença adequada.

- ritmo;
- progressão;

# 21. UX DO TESTE

Mobile First.

Cada pergunta deve possuir:

- legibilidade;
- grande área de toque;
- feedback visual;
- transição rápida;
- navegação anterior quando permitido;
- progresso;
- ausência de distrações.

Depois de selecionar uma resposta, avaliar conforme o formato se:

- avança automaticamente;

ou:

- exige "Continuar".

Não aplicar uma regra única para todos os tipos de pergunta.
