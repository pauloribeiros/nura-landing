# 1. CONTEXTO DO PRODUTO

Crie uma Landing Page premium, moderna, altamente responsiva e orientada à conversão para a:

# NURA

A NURA é uma plataforma digital de avaliações voltadas para descoberta pessoal, cognição, personalidade, comportamento, carreira e neurodiversidade.

A plataforma disponibilizará diferentes experiências, como:

* TDAH em Adultos;
* Espectro Autista em Adultos;
* Perfil Cognitivo / QI;
* Altas Habilidades / Superdotação;
* Personalidade;
* Inteligência Emocional;
* Memória;
* Atenção;
* Raciocínio;
* Perfil Profissional;
* outras avaliações futuras.

IMPORTANTE:

A NURA não deve parecer:

* um site de quizzes;
* um portal médico;
* uma clínica;
* um SaaS genérico;
* uma plataforma genérica de IA.

A percepção desejada é:

> tecnologia + ciência + autoconhecimento + curiosidade + confiança + experiência premium.

---

# 2. CONCEITO CENTRAL — NURA PERFIL

Substituir qualquer referência anterior a "Mind ID" por:

# NURA Perfil

O NURA Perfil é a representação visual e evolutiva das diferentes dimensões exploradas pelo usuário dentro da plataforma.

Cada nova avaliação acrescenta informações ao NURA Perfil.

Exemplo:

```text
SEU NURA PERFIL

Cognição           ●●●●○
Atenção            ●●●○○
Personalidade      ●●●●○
Comportamento      ●●○○○
Carreira           ○○○○○

42% explorado
```

IMPORTANTE:

Não criar uma "pontuação universal da pessoa".

Resultados metodologicamente diferentes não devem ser artificialmente combinados em uma única nota.

O percentual representa apenas quanto do ecossistema NURA o usuário já explorou.
